How CSS Combinators Work

This paragraph is the article introduction (lead text). It automatically gets a larger font size and a unique color because it comes immediately after the heading element.

This is the main body text of the article. It falls back to the standard paragraph styling, just like any other ordinary paragraph further down the page.

Another regular paragraph here. As you can see, the "h2 + p" rule has absolutely no effect on this text because it is not an immediate neighbor of the heading.
